# 待办清单（To-Do List）命令行工具

这是一个基于 Python 编写的命令行待办清单管理程序。完全由我独立开发完成。

## 🛠️ 功能特点
- 添加新的待办事项
- 查看所有待办事项（带完成状态 `[x]` / `[ ]`）
- 标记任务为已完成
- 删除不需要的任务
- 数据持久化：使用 JSON 格式将数据保存在本地硬盘，关掉程序数据也不丢。

## 💻 使用技术
- 语言：Python 3
- 核心库：`json`（数据存储）、`os`（系统交互）
- 版本控制：Git & GitHub
